# Task 0: Python Fundamentals, Data Analysis & Git

This repository contains solutions for Task 0, progressing from fundamental Python lists and loops to data analysis and visualization using NumPy, Pandas, and Matplotlib.

## Setup Instructions
1. Ensure Python 3.x is installed.
2. Install the required data science libraries:
   `pip install numpy pandas matplotlib`
3. Ensure the dataset `student_performance.csv` is located in the `data/` folder.

## Running the Code
Run each script individually from the root directory of the repository:
* `python q1.py` (List Analyzer)
* `python q2.py` (List Functions)
* `python q3.py` (Prime Numbers)
* `python q4.py` (NumPy Basics)
* `python q5.py` (Pandas CSV Analysis)
* `python q6.py` (Matplotlib Visualization)\n
